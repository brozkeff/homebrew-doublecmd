Double Commander for macOS

Unofficial Homebrew tap. Tracked stable release: 1.2.9. macOS 11 or newer.

Snapshot channel: revision 13524. Opt in by setting HOMEBREW_DOUBLE_COMMANDER_CHANNEL=snapshot in your shell environment. Run brew update and brew upgrade --cask brozkeff/doublecmd/double-commander. Remove the setting and upgrade again to return to the latest stable release, even when it is a downgrade.

The tap clears all extended attributes after each installation or upgrade. For manual installations, before first launch run:

xattr -cr "/Applications/Double Commander.app/"

Why this tap exists

The official cask was disabled for failing Gatekeeper checks. This tap offers an explicit sideloading path and checks SHA-256 hashes, without notarization or PGP signature verification.

Hashes verify downloaded bytes, not publisher identity. A compromised upstream account or build can publish malicious software with valid hashes. Clearing quarantine reduces macOS download protection. Weekly checks publish tap updates; they do not automatically upgrade your installed app.
